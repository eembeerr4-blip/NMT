# Прогрес розробки NMT Academy 3.0

Оновлено 17 жовтня 2026.

## Реалізовано

- Сторінка уроку `/learn/[topicId]`: цілі, час, відео, конспект, приклади, типові помилки, домашнє завдання, результат, наступне повторення, наступний урок.
- Урок не зараховується лише через відкриття. Якщо є перевірені завдання, потрібна завершена спроба.
- Після тесту оновлюються статус теми, журнал помилок, повторення і найближче незавершене заняття цієї теми.
- Інтервали повторення: 1/3/7 після слабкого результату або повторних помилок, 1/7/30 для середнього, 7/21/45 після засвоєння. Повторення видно в календарі.
- Конспекти для математики, української мови, історії України та біології. Статус «Перевірено». Інші предмети каталогу лишаються «Немає матеріалів».
- 154 нових авторських перевірених завдань. Математичні відповіді обчислюються в коді. У пробник потрапляють лише VERIFIED.
- Якщо завдань менше ніж 12, тест бере наявні й не дублює їх.
- YouTube: пошук через Data API, кеш пропозицій, підтвердження і відхилення, ролі лекцій, кнопка «Інше пояснення». Без ключа — чесне повідомлення і посилання на пошук. Вигаданих відео немає.
- Ollama: потокова відповідь, скасування, тайм-аут 120 с, історія діалогу користувача. Кнопки «Я не зрозумів», «Поясни простіше», «Покажи приклад», «Розбери покроково», «Дай підказку», «Перевір моє рішення», «Знайди інше відео».
- Локальну модель вмикають кнопкою. За замовчуванням AI вимкнений, решта сайту працює.
- Сім історичних результатів власника не змінювались.

## Перевірено

- Резервна копія: `prisma/backups/dev-before-lessons-20261017.db`.
- Після seed: 7 seed-результатів, ті самі сирі й рейтингові значення.
- Ollama 0.40.2, RTX 4060 8 ГБ. Модель `qwen3:4b` українською правильно відповіла на рівняння `2x+3=11` (корінь 4), «не знаю», хрещення 988 / Володимир, мітохондрія і АТФ.
- Поток відповіді Ollama отримано і обірвано після двох фрагментів.
- TypeScript, ESLint, 17 модульних тестів, production build.
- Playwright: 14 сценаріїв на `prisma/e2e.db`, включно з уроком, який не завершується без практики.

## Поточні проблеми

- Ключа YouTube немає, тож автоматичний пошук на цій машині не виконувався. Підключених відео: 0.
- Відповідь AI в інтерфейсі під сесією власника не проганялась: пароль власника ще не задано, і його не змінювали.
- Предмети на вибір, крім біології, без конспектів і завдань.
- Офіційний формат НМТ-2027 не підтверджено в застосунку.
- Досягнення досі спільні за старими ідентифікаторами.

## Наступні задачі

- Задати пароль власника на `/onboarding` і на уроці натиснути «Увімкнути локальну Ollama».
- Додати ключ YouTube у налаштуваннях, якщо потрібен автоматичний пошук.
- Наповнити предмети на вибір так само, як чотири предмети власника.
- Розвести досягнення по користувачах.

## Команди

```bash
npm run dev
npm run typecheck
npm run lint
npm test
npm run test:e2e
```

Ollama вже встановлена. Сервер: `ollama serve`. Нові моделі не завантажувались.

## База

`DATABASE_URL=file:./dev.db`. Тести Playwright пишуть лише в `prisma/e2e.db`.
