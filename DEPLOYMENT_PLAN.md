# Майбутній публічний запуск

Цей документ нічого не розгортає. Зараз сайт лишається на localhost.

## Що вже готове до переносу

- Персональні записи мають `userId`.
- Сесія зберігається в базі як хеш токена. Пароль зберігається як scrypt, не відкритим текстом.
- Сервер не довіряє ідентифікатору користувача з форми: дії читають сесію.
- Ключі API лежать у `data/secrets.json` і не потрапляють у Git.
- Схема Prisma не використовує типи, властиві лише SQLite.

## Кроки, коли буде окреме рішення про запуск

1. Підняти PostgreSQL і змінити `provider` та `DATABASE_URL`.
2. Зробити резервну копію SQLite і перенести дані скриптом, не через скидання бази.
3. Увімкнути HTTPS і `secure` cookie.
4. Прибрати локальний вхід власника без пароля. Він уже обмежений хостом localhost.
5. Задати резервне копіювання бази за розкладом.
6. Не вмикати платні AI-провайдери без явного ключа користувача.
7. Окремо вирішити, чи потрібен `APP_PASSWORD` поверх облікових записів.

Публічний домен, хостинг і платні сервіси зараз не налаштовуються.
