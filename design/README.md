# NMT Academy UI

Еталон: [дев’ять погоджених екранів](reference/nine-screens.png).
Кольори обох тем, радіус і тіні: `src/app/globals.css`. Шрифт Inter, кирилиця, через `next/font`.

Основні компоненти — `src/components/ui.tsx`: Button, Card, PageHeader, EmptyState, ErrorState, LoadingState, FormField, Stat, ProgressBar, Badge. `ContentTabs` і `PanelDialog` використовують доступні примітиви Radix. Зберігайте постійні підписи полів, видимий фокус, pending і відповідь сервера.

`DataTable` залишає пошук/фільтри/пагінацію серверній сторінці. Передавайте `data-label` для кожного `td`: на телефоні рядок стає підписаною карткою, усі дії залишаються доступними. Спільні таблиці не повинні приховувати персональні дані інших учнів за клієнтським фільтром — права й ownership перевіряються сервером.

Стан матеріалу та навчальний прогрес — різні речі. Порожня тема показує «Матеріал готується», прочитаний конспект не означає «Засвоєно». Не підставляйте статистику або декоративні відео.

Знімки QA в `design/screenshots/` не комітяться. Детальна інвентаризація: `audit/reports/03-design-system.md`.
