# NMT Academy

Персональна платформа підготовки до НМТ-2027. Інтерфейс українською. Дані зберігаються в локальній SQLite і не зникають після перезапуску. Кожен профіль має власні предмети, календар, тести й аналітику. Бібліотека тем спільна.

Перший запуск власника наявних результатів: відкрийте http://localhost:3000/onboarding і натисніть «Це мій наявний прогрес», потім задайте пароль. Нікнейм власника — `owner`. Новий учень створює окремий профіль на тій самій сторінці.

Нікнейми нормалізуються до NFKC і нижнього регістру. Міграція `20261018130000_nickname_case_insensitive` додає SQLite-обмеження унікальності без урахування регістру; вона не змінює наявні профілі й безпечно зупиниться, якщо перед застосуванням виявить дублікати.

Урок теми: `/learn/[id]`. AI-функції вимкнені. Без наявних перевірених посилань відео не підставляються. Покриття матеріалів: `CONTENT_COVERAGE.md`.

## Запуск

Запустіть `START_NMT_ACADEMY.cmd` у корені проєкту. Вікно консолі потрібно залишити відкритим під час роботи; натисніть `Ctrl+C`, щоб зупинити сайт.

Відкрийте http://localhost:3000. Сценарій перевіряє залежності та порт 3000 і запускає локальний dev-сервер. Він не скидає, не заповнює і не мігрує базу. Для запуску вручну: `npm.cmd run dev -- --hostname 127.0.0.1 --port 3000`.

Якщо залежності справді відсутні, спочатку встановіть їх через `npm install`. Не запускайте команди reset/setup/seed для звичайного запуску чинного профілю та його даних.

Локальний сайт доступний лише поки комп’ютер увімкнений і сервер працює. Автозапуск Windows та зовнішній хостинг не налаштовуються цим сценарієм.

## Змінні середовища

Скопіюйте `.env.example` у `.env`.

- `DATABASE_URL` — SQLite зараз. Для PostgreSQL змініть провайдер у `prisma/schema.prisma` і рядок підключення. Схема не використовує типи, притаманні лише SQLite.
- `APP_PASSWORD` — якщо задати, сайт вимагає пароль. Для локальної роботи залиште порожнім.
- `OPENAI_API_KEY`, `GEMINI_API_KEY`, `OLLAMA_BASE_URL`, `YOUTUBE_API_KEY` — необов'язкові. Навчання, тести, календар і аналітика працюють без них.

Ключі, введені в налаштуваннях, записуються в `data/secrets.json`. Цей файл не входить до Git і не віддається в браузер.

## Що вже рахується чесно

- Дата НМТ не вигадана. Поки її немає в налаштуваннях, лічильник показує «Дату не задано».
- YouTube-посилання не підставляються. Пошук через YouTube Data API вмикається лише з ключем.
- Рейтинговий бал не виводиться з тестового без офіційної таблиці. Таблицю можна додати в налаштуваннях JSON, коли вона буде опублікована.
- Формат НМТ-2027 у конфігурації позначено як непідтверджений.
- Стартові результати за вересень і жовтень 2026 записані окремо, без додуманих полів.
- У банк додано авторські тренувальні завдання лише для чотирьох тем. Вони прямо позначені як неофіційні.

Активна підготовка в календарі починається 19 жовтня 2026. Перший пробник ротації — математика, 24 жовтня 2026.

## Вхід через HTTP у локальній мережі

Для локального HTTP-сайту, запущеного через npm run start, задайте SESSION_COOKIE_SECURE=false у .env, потім перезапустіть сервер. Без цієї настройки production-cookie вимагає HTTPS і браузер не зберігає вхід за адресою http://192.168.88.10:3000. Для HTTPS приберіть цю настройку або встановіть true. Перевірка пароля і серверної сесії залишається обов'язковою.

### Обновление после аудита (17.10.2026)

Существующую базу не нужно пересоздавать. Перед обновлением используйте `npm run db:upgrade:personal-video`: команда делает согласованную SQLite-копию в `prisma/backups`, добавляет личный прогресс видео и поля ролей, проверяет целостность и неизменность количества учебных записей. Старые общие поля видео остаются для сохранности; личные заметки и позиция читаются из `UserVideoProgress`. Исторические общие записи перенесены только владельцу, остальные ученики начинают со своей позиции.

После изменения схемы остановите локальные серверы перед `npx prisma generate`: Windows блокирует загруженный файл Prisma. Затем выполните сборку и запустите сайт.

`npm run content:upgrade` устанавливает пять расширенных базовых объяснений, 12 авторских упражнений по процентам и два видео ВШО. Перед изменением создаётся отдельная копия. Лекция по линейным уравнениям проверена на воспроизведение; ролик по орфографии остаётся кандидатом. Команда не заменяет пользовательскую базу и не меняет результаты. Новые упражнения имеют постоянные ID и не размножаются при повторном запуске. Перед повторным запуском учитывайте, что пять включённых объяснений будут обновлены из пакета.

`npm run content:audit` читает базу и выводит матрицу готовности; `npm run content:audit -- --strict` возвращает ненулевой статус, пока существуют незаполненные уроки. Готовность комплекта не является подтверждением программы НМТ-2027 или сертификацией методического качества.

Ролі: STUDENT — особисте навчання, EDITOR — редагування спільної бібліотеки, ADMIN — адміністративна панель і керування платформою; власник зберігає адміністративний доступ. Доступ до `/admin` перевіряється на сервері для ADMIN і власника. Призначити роль OWNER не можна; власну роль і роль власника змінити через керування користувачами не можна. Не публікуйте облікові дані й API-ключі.

Резервная копия формата 3 включает роли, состояние диагностики и личные записи видео. Формат 2 принимается без этих новых записей; формат 1 отклоняется как неполный. Восстановление завершает сессии — потребуется повторный вход.

Интеграционные проверки запускаются только при `NMT_AUDIT_DB=1` и `DATABASE_URL=file:./audit-20261017.e2e.db`. Файлы `tests/audit-database.test.ts` и `tests/plan-upgrade.test.ts` запускайте последовательно: первый восстанавливает тестовую базу. Рабочую базу для этих тестов не используйте.
