# NMT Academy

Персональна платформа підготовки до НМТ-2027. Інтерфейс українською. Дані зберігаються в локальній SQLite і не зникають після перезапуску. Кожен профіль має власні предмети, календар, тести й аналітику. Бібліотека тем спільна.

Перший запуск власника наявних результатів: відкрийте http://localhost:3000/onboarding і натисніть «Це мій наявний прогрес», потім задайте пароль. Нікнейм власника — `owner`. Новий учень створює окремий профіль на тій самій сторінці.

Урок теми: `/learn/[id]`. Локальний репетитор вмикається на сторінці уроку кнопкою «Увімкнути локальну Ollama», якщо `ollama serve` уже запущений. Без ключа YouTube відео не вигадуються. Покриття матеріалів: `CONTENT_COVERAGE.md`.

## Запуск

```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

Відкрийте http://localhost:3000.

Повторне встановлення бази разом із стартовими даними:

```bash
npm run db:setup
```

`db:setup` створює міграцію. Якщо міграція вже є, достатньо `npx prisma migrate dev` і `npm run db:seed`. Повторний seed не затирає змінені історичні результати: наявні записи з тими самими ідентифікаторами лишаються як є.

## Перевірки

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

Перед e2e один раз встановіть браузер Playwright: `npx playwright install chromium`.

## Змінні середовища

Скопіюйте `.env.example` у `.env`.

- `DATABASE_URL` — SQLite зараз. Для PostgreSQL змініть провайдер у `prisma/schema.prisma` і рядок підключення. Схема не використовує типи, притаманні лише SQLite.
- `APP_PASSWORD` — якщо задати, сайт вимагає пароль. Для локальної роботи залиште порожнім.
- `OPENAI_API_KEY`, `GEMINI_API_KEY`, `OLLAMA_BASE_URL`, `YOUTUBE_API_KEY` — необов'язкові. Навчання, тести, календар і аналітика працюють без них.

Ключі, введені в налаштуваннях, записуються в `data/secrets.json`. Цей файл не входить до Git і не віддається в браузер.

## Що вже рахується чесно

- Дата НМТ не вигадана. Поки її немає в налаштуваннях, лічильник показує «Дату не задано».
- YouTube-посилання не підставляються. Пошук через YouTube Data API вмикається лише з ключем.
- Рейтинговий бал не виводиться з тестового без офіційної таблиці. Таблицю можна додати в налаштуваннях JSON, коли вона буде опублікована.
- Формат НМТ-2027 у конфігурації позначено як непідтверджений.
- Стартові результати за вересень і жовтень 2026 записані окремо, без додуманих полів.
- У банк додано авторські тренувальні завдання лише для чотирьох тем. Вони прямо позначені як неофіційні.

Активна підготовка в календарі починається 19 жовтня 2026. Перший пробник ротації — математика, 24 жовтня 2026.
